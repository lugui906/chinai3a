Capabilities

它能为你做什么

不是只会聊天的对话框——而是一个能动手操作手机的助手。

视觉

看屏幕 · 视觉理解

系统录屏实时截图，交给视觉模型真正「看」屏幕。画布、游戏、视频这类没有文字标签的界面也能理解。

控件树

读控件树 · 结构化理解

通过无障碍服务读取界面控件树，拿到按钮文字、输入框、列表项等结构与层级，配合视觉模型，看得更准、点得更稳。

按文字点击 · 精准操作

先识别屏幕文字再点击目标，而不是猜坐标。支持点击、滑动、长按、滚动与返回 / 桌面 / 多任务。

读文档 · 本地解析

直接读 docx / pptx / xlsx / pdf 和图片、纯文本，把内容抽成文字交给 AI，不用你先手动转换。

联网搜索 · 网页抓取

内置搜索与网页抓取，能查最新资料、抓正文再总结，不局限于模型自己的旧记忆。

记忆

长期记忆

把最近对话总结成习惯、职业、常用 App 等画像，存进本机并注入下次对话——越用越懂你。

后台干活 · 通知回来

驱动别的 App 时它必然在后台。任务进行中挂一条进度通知，完成自动提醒，点一下切回 ChinAI3。

多目录文件读写

可授权任意多个文件夹，重启也能记住。AI 能读取、写入、重命名、复制、移动你的真实文件。

熟悉的对话界面

聊天、思考过程、工具调用时间线一并呈现，随时看到 AI 此刻在看什么、点了哪里、做了什么。

不设硬性步数上限

长任务不会被硬砍。改用循环检测：连续重复同一个动作才介入，合法的一长串步骤照常跑完。

How It Sees

它是怎么理解屏幕的

两条通道同时工作：看得见画面，也读得到结构。既能看懂游戏和画布，也能精准点到按钮。

视觉通道
系统录屏截图 → 视觉模型理解画面，ML Kit 中文 OCR 兜底识别文字
结构通道
无障碍服务读取界面控件树，拿到按钮、输入框、列表项等文字与层级
点击方式
按文字精准点击，坐标点击为辅；滑动、长按、滚动一应俱全
系统按键
返回 / 桌面 / 多任务，一键直达
输入文字
聚焦输入框后直接写入，不用模拟键盘
文件访问
私有目录 + 你授权的目录，可读可写、可改名可复制
两条通道互相兜底：控件树负责精准定位，视觉负责看懂画面。遇到没有控件信息的界面（游戏、画布、视频），视觉通道照样能正常工作。

Get Started

四步上手

装好之后，按顺序把「眼睛」「手」「大脑」都准备好。

1

下载 APK 并安装（首次需允许「安装未知来源应用」），打开 ChinAI3，进入底部「权限 / 设置」。

2

授予屏幕录制 —— 这是 AI 的「眼睛」，它才能截图看懂屏幕。

3

开启无障碍 —— 这是 AI 的「手」。路径：设置 → 无障碍 → 已安装的服务 → ChinAI3 屏幕控制。关掉后仍可看屏幕，但无法点击。

4

填 API Key —— 这是 AI 的「大脑」。默认服务地址 https://api.deepseek.com，模型 deepseek-v4-flash-vision-exp。可选：授权一个文件夹，它就能读写你的真实文件。

FAQ

常见问题

为什么需要屏幕录制权限？

这是它的「眼睛」。安卓上 AI 无法直接读取别的 App 的界面内容，只能通过系统录屏拿到屏幕画面，再交给视觉模型理解。截图只在你本机处理，只有当前任务需要的画面才会发给模型。

为什么需要无障碍权限？关掉会怎样？

无障碍是安卓上唯一无需 root、无需改机的触摸注入途径，即它的「手」。关掉之后它仍能看屏幕、识别文字、回答问题，只是无法点击操作——不会整个失效。

提示无法安装 / 解析包错误？

多半是机型不匹配。此版本只含 arm64-v8a 原生库，需要 64 位 ARM 处理器且系统为 Android 8.0 及以上。32 位老机型、部分 x86 模拟器无法安装。

要自己准备 API Key 吗？

要。App 本身不内置密钥，需要你填自己的 DeepSeek API Key（服务地址默认 https://api.deepseek.com）。密钥只保存在本机 App 私有目录。

它能读哪些格式的文件？

支持 .docx / .pptx / .xlsx / .pdf、图片和纯文本。Word / PPT / Excel 通过解析文档本身抽取文字，PDF 用 pdfbox，图片则走视觉模型识别。

会不会一直烧 token？

没有硬性步数上限，但内置循环检测：连续重复同一个动作会先警告、再中止。参数不同的长任务（比如滚动浏览很长的列表）不会被误伤。

手机上它会一直在后台吗？

它驱动的是别的 App，所以运行时必然在后台。任务期间会有进度通知，完成后可自动切回。Android 13 及以上会请求通知权限，不授权也不影响使用。
